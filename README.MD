## 📘 详细文档

### 1. 公区智能控制
**精细化的公区照明与空调管理方案。**
适用于客厅、餐厅、玄关、厨房等公共区域。

- **日夜分灯**: 白天开启主灯（高亮/冷光），夜间开启专用夜灯（低亮/暖光）。
- **多点触发**: 支持主传感器（如吸顶微波）和多个副传感器（如各房间门口）共同触发预亮。
- **光照干扰修正**: 如果邻近区域灯亮着，自动忽略光照阈值强制开灯（避免因其他灯光导致的光照虚高而不开灯）。
- **空调联动**: 无人长时间延时后自动关闭空调。

### 2. 公区设备智能关闭 (全员就寝)
**解决“睡觉忘关灯/关电视”的终极方案。**

- **全员检测**: 只有当所有在家的家庭成员都处于“床上”状态（需配合压力传感器或手机充电状态等）时触发。
- **防抖动机制**: 全员在床后等待 N 分钟（默认 3 分钟），确认无人下床才执行关闭。
- **多设备支持**: 一键关闭灯光、媒体设备（电视/音响）、空调等。

### 3. 场景模式选择器 (8路回弹·容错版)
**让 Input Select 变身多功能场景面板。**

- **主要功能**: 将下拉菜单 (Input Select) 变成一个可触发 8 个不同 Script 的控制器。
- **自动回弹**: 执行完脚本后自动跳回“请选择”状态，解决 Input Select 无法连续触发同一选项的问题。
- **智能容错**: 忽略选项名称前后的空格。

### 4. 卧室套房智能控制
**全功能的卧室自动化管家。**

- **进门模式**: 正常时间进门自动开灯，可设定亮度色温。
- **睡眠守护**: 睡眠模式下（或半夜），他人进入房间或开门只开启微弱夜灯，不打扰休息。
- **自动关断**: 人走后分级延时——短时间无人关灯，长时间无人关空调。
- **防误触**: 结合床铺压力传感器和套房内其他房间（如主卫）状态，确保人在床上或在套房内活动时绝不误关灯。

### 5. 智能起夜模式
**贴心的夜间行动向导。**

- **全流程管理**: 入睡监测 -> 起夜下床 -> 路径照明 -> 回床关闭。
- **多路径支持**: 支持配置三条不同路径（如去厕所、去客厅、去厨房）的灯光。
- **状态同步**: 自动管理“睡眠模式”和“起夜模式”状态。

### 6. 卧室进入夜灯模式
**简单的门口夜灯逻辑 (轻量级)。**
*注：功能与 `卧室套房智能控制` 有重叠，此蓝图更侧重于通过门磁和红外判断“从外进入”的单一场景。*

- 当检测到卧室门被打开，且门外红外最近有触发（证明是走进去的），同时卧室内处于睡眠模式时，开启夜灯。

### 7. 卫生间智能控制 (双状态机·精准控制版)
**极其强大的卫生间自动化系统。**

- **多区域跟随**: 哪怕卫生间有干区、湿区、马桶区，灯光也能完美随人移动。
- **洗澡模式 (核心)**: 通过水浸传感器检测淋浴水流，自动锁定“洗澡中”状态。
    - 洗澡期间：循环泵常开（保证热水），浴霸开暖风，自动关窗保温。
- **智能除湿**: 洗澡结束后，自动开启除湿流程（排气扇+开窗），直到湿度降至对比值（如客厅湿度）以下。
- **循环泵逻辑**: 平时进人根据气温自动预热循环水。

### 8. 地暖全能主控
**结合天气预报的智能地暖控制。**

- **拒绝“假回暖”**: 结合 `sensor.today_max_temp` (今日最高温)，即使中午出太阳实时气温升高，只要预报全天寒冷，依然锁定高水温运行。
- **分时控温**: 早安模式、白天节能模式、晚安模式、睡眠模式自动切换。
- **负载保护**: 当任意卧室开启地暖时，强制开启客厅地暖（作为主负载），保护锅炉。
- **林内锅炉对接**: 直接控制锅炉开关与出水温度。

### 9. 区域灯光控制 (色温和亮度)
**区域级灯光批量调控工具。**

- 配合 Input Select 用于面板或仪表盘。
- 选择一个区域（如“主卧”），即可批量调整该区域内所有**已开启**灯光的亮度和色温。

### 10. 智能阳光窗帘控制
**采光与遮阳的平衡艺术。**

- **阳光直射保护**: 结合太阳方位角和高度角，只在阳光真正晒进窗户时才关闭窗帘。
- **自动恢复**: 阳光移走后，自动打开窗帘（可配置是否需要有人才打开）。

### 11. 无线窗帘电动窗单键循环控制
**单按钮控制窗帘的完美逻辑。**

- **动作循环**: 按一下 开 -> 再按 停 -> 再按 关 -> 再按 停。
- **状态追踪**: 即使通过其他方式（如语音）控制了窗帘，本蓝图也能通过计算运行时间，知道下次按键该往哪个方向。

### 12. 基于时间的电动窗模拟定位控制
**让普通电机变身智能伺服。**

- 适用于只有 开/关/停 且不支持百分比控制的老式电机或普通的继电器控制窗。
- **时间模拟**: 通过测量全开全关所需秒数，利用时间差精确控制窗户停在 50% 或 15% 等任意位置。

## 🚀 使用方法

1. **导入蓝图**:
   将 `blueprints` 目录下的 `.yaml` 文件复制到 Home Assistant 配置目录的 `blueprints/automation/antigravity/` (或其他自定义子文件夹) 下。

2. **创建自动化**:
   在 Home Assistant 中，进入 **配置** -> **自动化与场景** -> **蓝图**，找到对应的蓝图点击“创建自动化”。

3. **配置参数**:
   仔细阅读每个蓝图的描述，根据提示选择实体。标有 `(必选)` 的通常是核心传感器，标有 `(可选)` 的可以留空。

## ⚠️ 注意事项

- 部分蓝图（如地暖、卫生间）依赖特定的 `input_boolean` 或辅助实体，请务必查看蓝图描述中的要求。
- 建议先在测试环境或单个房间测试，参数调整满意后再全屋推广。
